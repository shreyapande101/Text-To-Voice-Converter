# Text to Voice Converter 

This is a simple **Text to Voice Converter** project made using **HTML, CSS, and JavaScript**.  
It converts the text entered by the user into speech. It have different english accent according to different country

---

 Features

- Convert written text into voice
- Simple and clean user interface
- Beginner-friendly project

---

 Language Used

- **HTML** – for structure  
- **CSS** – for styling  
- **JavaScript** – for text to speech functionality  

---
 How to Use
1. Type any text in the input box
2. Select the accent
3. Click on the **Convert** button
4. The text will be converted into voice
